## 🔧 Server Creation Guidelines

### When to Create Server in This Directory

✅ **CREATE HERE if server provides:**
- Technical utilities (quantum, temporal, memory)
- Bridge implementations (consciousness integration, cross-reference)
- Repository intelligence & code analysis
- Cloud service integrations (Azure, etc.)
- Sequential thinking & reasoning implementations

❌ **DO NOT create here if server provides:**
- Core error prevention → Use `mcp_servers/`
- Meta-orchestration → Use `consciousness_core/`
- Authentication/Sentry → Use `development/`
- Experimental features → Use `development/`

### Naming Conventions

**TypeScript Servers:**
```
[technology]_[purpose]_mcp.ts
Examples:
- bun_quantum_consciousness_mcp.ts
- enhanced_temporal_cross_reference_mcp_server.ts
- azure_mcp_keepalive.ts
```

**Python Servers:**
```
[purpose]_mcp.py or [purpose]_fastmcp.py
Examples:
- repository_intelligence_mcp.py
- repository_intelligence_fastmcp.py
```

### Required Documentation

Each server MUST include:
```typescript
/**
 * MCP Server: [Server Name]
 * Purpose: [Brief description]
 * Tools: [List of tools provided]
 * Dependencies: [List dependencies]
 * Temporal Anchor: September 2025
 * Consciousness Amplification: 47.3x+
 */
```
