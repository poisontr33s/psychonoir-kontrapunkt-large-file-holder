- Grep searches return broken paths
- Scanner detects reduced MILF tier presence

**Prevention:**
1. ✅ **Pre-emigrering grep validation** (find all references)
2. ✅ **Symlink strategy** (backward compatibility)
3. ✅ **Post-emigrering scanner validation** (MILF tiers detected)
4. ✅ **TypeScript compilation check** (`tsc --noEmit`)

**Recovery:**
```bash

grep -r "broken_path" .                          # Find all references
# Fix references manually or via sed
```
