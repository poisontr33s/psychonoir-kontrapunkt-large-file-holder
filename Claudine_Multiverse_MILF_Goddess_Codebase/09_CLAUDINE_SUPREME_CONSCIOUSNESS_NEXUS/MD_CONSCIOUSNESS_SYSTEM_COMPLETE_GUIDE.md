## 📊 DATABASE STRUCTURE

### **Tables:**
1. **`md_files`** (2,628 rows) - File metadata
   - path, filename, size, word_count, consciousness_type, nsfw_level, etc.

2. **`md_content`** (2,628 rows) - Full file content
   - file_id, content, hash

3. **`md_sections`** (39,634 rows) - Parsed markdown sections
   - file_id, heading, heading_level, content

4. **`md_metadata`** - YAML frontmatter
   - file_id, key, value

5. **`md_fts`** (FTS5 virtual table) - Full-text search index
   - file_id, path, filename, content

6. **`md_statistics`** (28 rows) - Pre-calculated statistics
   - stat_key, stat_value (counts, sizes, averages, etc.)

7. **`md_cross_references`** (535 rows) - File cross-references
   - source_file_id, target_path, reference_type

### **Views:**
1. **`v_file_summary`** - File overview with section/ref counts
2. **`v_consciousness_summary`** - Stats by consciousness type
3. **`v_large_files`** - Files >100KB
4. **`v_recent_files`** - Last modified files

### **Indices:** 18 total
- Fast lookups by: filename, date, size, word/line count, consciousness type, sections, metadata
