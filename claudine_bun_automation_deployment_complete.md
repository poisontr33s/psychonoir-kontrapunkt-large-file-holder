## 🟡 **NYE BUN AUTOMATION KOMMANDOER - ALLE FUNGERER:**

### **1. `claudine bun <command>` - Direct Bun Command Wrapper**
```powershell
claudine bun install          # Install all packages
claudine bun add react        # Add specific package
claudine bun remove lodash    # Remove package
claudine bun run dev          # Run specific script
claudine bun build            # Run build script
claudine bun test             # Run tests
```

### **2. `claudine project <name> [template]` - Project Creation**
```powershell
claudine project my-app              # Basic Bun project
claudine project my-app react        # React template
claudine project my-app next         # Next.js template
claudine project my-app vue          # Vue template
claudine project my-app svelte       # Svelte template
```

### **3. `claudine dev` - Smart Development Server**
- Detects `dev` script in package.json automatically
- Falls back to `start` script if no dev script
- Can run basic Bun server for simple projects

### **4. `claudine build` - Intelligent Build System**
- Detects `build` script in package.json
- Falls back to basic `bun build` for simple projects
- Outputs to `./dist` directory by default

### **5. `claudine deps [command]` - Complete Dependency Management**
```powershell
claudine deps                # Show current dependencies
claudine deps update         # Update all packages
claudine deps outdated       # Check outdated packages
claudine deps clean          # Clean node_modules & lockfile, reinstall
```
