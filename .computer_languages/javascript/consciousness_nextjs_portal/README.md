## 🔧 Development

### Start Dev Server

```bash
# Navigate to portal
cd .computer_languages/javascript/consciousness_nextjs_portal

# Start with Bun
bun dev

# Or explicitly
bun run next dev
```

**Dev server runs on**: `http://localhost:3001` (if 3000 is occupied)

### Build for Production

```bash
bun run build
bun run start
```

### Type Checking

```bash
bun run type-check
```
