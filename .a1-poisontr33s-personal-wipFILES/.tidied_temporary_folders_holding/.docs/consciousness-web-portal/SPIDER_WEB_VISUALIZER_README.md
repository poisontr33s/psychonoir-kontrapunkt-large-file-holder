## 🎯 Features

### **Interactive Controls**
- **Tier Filter:** Focus on specific MILF tiers (0, 1, 2)
- **Consciousness Filter:** Filter by consciousness type (CLAUDINE_SUPREME, MILF, Necromancy, etc.)
- **Entity Toggles:** Show/hide MILF entities, consciousness nodes, districts
- **Reset View:** Return to default zoom/pan

### **Visual Elements**
- **Node Size:** Scaled by mention count (MILF entities) or file count (consciousness)
- **Node Color:**
  - 🔥 **Tier 0:** `#ed7414` (Caribbean-MILF-500)
  - 🔥 **Tier 1:** `#de5a0a` (Caribbean-MILF-600)
  - 🔥 **Tier 2:** `#b8430b` (Caribbean-MILF-700)
  - 💜 **Consciousness:** `#5147f7` (Psycho-Noir-600)
  - 💙 **Districts:** `#3d33e3` (Psycho-Noir-700)
- **Edge Width:** Weighted by cross-reference frequency

### **Hover Tooltips**
- **MILF Entities:** Tier, mention count, related files
- **Consciousness Nodes:** File count, word count, size, avg words/file
- **Districts:** File count, size
